# Assumptions and project policies

This file records every project policy (class **P**) and every open uncertainty in the AK4522 DAC model. A policy is a deliberate choice made where [DS] is silent or ambiguous, so that software behavior is deterministic and testable. It is not a claim about the silicon.

Each policy names the evidence it rests on (IDs from [evidence.md](evidence.md)), why it was chosen, what would replace it, and the test that pins it down. A policy changes only when the replacement evidence or a project-owner decision is recorded here.

Status values: *adopted* (in force for implementation), *provisional* (adopted pending a planned check), *superseded* (kept for history).

| P-37 | Sample rates are represented exactly as integers in micro-hertz; the converter ratio is their reduced fraction P / Q, and output timing advances by an exact integer index and remainder, so no drift accumulates | REQ-RATE-02 requires no long-term sample-count drift; all supported rates are whole hertz | none | Rates finer than 1 uHz are needed | `[rate]` | adopted |
| P-38 | Converter kernel: Kaiser-windowed sinc designed for 125 dB; passband edge 20/44.1 of the lower rate and stopband edge at the lower rate minus the passband edge, unless given; cutoff midway; every phase row normalized to exact unity DC gain. Output m is written when input floor(m P / Q) + W has arrived, a fixed delay of W input samples | 125 dB leaves margin over the 120 dB target (P-33). | P-39 | Host latency alignment: with R = host frames per DAC frame, the core's 14.7-frame delay is 14.7 R host frames. The output FIFO is prefilled with D = ceil(W1 + (phi + W2 + 16) R / 8) + 2 zeros (W1, W2: converter half-widths; W1 = 0 when the input converter is bypassed at equal rates). Reported latency is D + K whole host frames. Both converters are symmetric about the times their outputs represent, so they add no group delay of their own | REQ-LAT-03 asks for an integer report matching the emitted audio; shifting the converter's time origin aligns the fraction with no extra filter.
