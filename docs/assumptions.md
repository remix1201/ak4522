# Assumptions and project policies

This file records every project policy (class **P**) and every open uncertainty in the AK4522 DAC model. A policy is a deliberate choice made where [DS] is silent or ambiguous, so that software behavior is deterministic and testable. It is not a claim about the silicon.

Each policy names the evidence it rests on (IDs from [evidence.md](evidence.md)), why it was chosen, what would replace it, and the test that pins it down. A policy changes only when the replacement evidence or a project-owner decision is recorded here.

Status values: *adopted* (in force for implementation), *provisional* (adopted pending a planned check), *superseded* (kept for history).

## Open uncertainties

These are unknown and are not resolved by any policy above. They limit the fidelity claims the project can make.

| ---- | -------------------------------------------------------------------------------- | --------------------------- | ------------------------------------------ |
| U-01 | Interpolator coefficients, structure (single or multistage), and word lengths    | Filter response, latency    | Measurement; cannot be recovered exactly   |
| U-02 | Modulator order, quantizer levels, dither, and noise shaping                     | Noise spectrum, idle tones  | Measurement of ultrasonic output spectrum  |
| U-03 | SCF and CTF pole frequencies and damping                                         | Combined response, phase    | Swept response measurement                 |
| U-04 | Stopband behavior beyond the 24.1/44.1 fs edge                                   | Image levels                | Wideband measurement                       |
